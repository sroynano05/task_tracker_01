### How To Run 
## Step 01 
### Run This Command First In The Bash
```bash :Bash
# Bash
alias task_cli='npm run task_cli'
```
## step 02:
```bash
task_cli add <id> "<my_discription>" # To add something in the list with id and my_discription as discription
task_cli delete <id> # delete <id>
task_cli read # read all task(s)
task_cli mark <id> <"todo" or "done"> # To either mark the task "done" or "todo"
task_cli update <id> <"updated_description"> # Just to  add updated Description in <id> specified 
```
